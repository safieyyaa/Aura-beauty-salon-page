Aura Beauty

Aura Beauty is a university front-end web project for a beauty salon and wellness platform. The website combines beauty services, beauty products, appointment booking, shopping cart, and wishlist features within a multi-page interface.

Project Overview

Aura Beauty is designed to provide users with a simple, attractive, and easy-to-navigate platform for exploring beauty and wellness services and products.

The website includes the following sections:

- Hair Services
- Makeup Services
- Manicure Services
- Facial and Spa Treatments
- Beauty Products
- Appointment Booking
- Shopping Cart
- Wishlist

Beauty Products

The website includes beauty products organized into different categories:

- Hair products
- Makeup products
- Manicure products and tools

Each product includes an image, description, price, and Add to Cart option.

Appointment Booking

The booking interface allows users to:

- Enter contact information
- Select a main service category
- Select related services
- Choose a preferred date and time
- Confirm a reservation
- View a booking summary
- Cancel the booking or return to the website

JavaScript is used to dynamically update available service options and generate the booking summary.

Project Purpose

This project was developed as a university academic project to practice and demonstrate front-end web development concepts, including:

- Multi-page website development
- HTML page structure
- CSS styling and layouts
- Responsive web design
- JavaScript interactions
- Website navigation
- Service and product presentation
- Appointment booking logic
- Shopping cart and wishlist interfaces
- Collaborative web development

Future Improvements

Possible future improvements include:

- User registration and authentication
- Database integration
- Persistent shopping cart and wishlist
- Online payment integration
- Admin dashboard
- Real-time appointment availability
- Improved mobile responsiveness
- Advanced form validation
- Deployment as a live website

Project Scope

Aura Beauty is currently an academic front-end project focused on the user interface and browser-side interactions.

The project does not currently include a production backend, database, online payment system, or real appointment-management server.

Team Project

Aura Beauty was developed as a collaborative university project using HTML, CSS, and JavaScript.
